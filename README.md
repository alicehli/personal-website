# Alice Li - Personal Portfolio

A modern, responsive personal portfolio website showcasing photography, writing, and reading at the intersection of data engineering and storytelling.

## Features

- **Modern Design**: Clean design with smooth animations and gradient backgrounds
- **Responsive Layout**: Fully responsive design that works on all devices
- **Multiple Sections**:
  - Hero section with photo grid and typewriter effect
  - Photography gallery page
  - Writing/essays section
  - Horizontal scrolling book carousel with Google Books API integration
  - Contact information with social links

## Project Structure

```
personal-website/
├── index.html      # Main page with hero, reading, and contact sections
├── gallery.html    # Photography gallery page / TODO
├── writing.html    # Writing/essays page / TODO 
├── styles.css      # All CSS styles
├── script.js       # JavaScript functionality and Google Books API integration
├── data.js         # Content data (personal info, books, photos)
├── icons.js        # SVG icon definitions
└── images/         # Photo assets
```

## Setup

1. Clone or download this repository
2. Open `index.html` in a web browser
3. That's it! No build process required.

## Development

The site is built with vanilla HTML, CSS, and JavaScript - no frameworks or build tools needed. Simply edit the files and refresh your browser.

### Customization

- **Content**: Update `data.js` for personal information, books, and photos
- **Colors**: Edit CSS variables in `styles.css`
- **Functionality**: Modify `script.js` for additional interactions

## Technologies

- Vanilla JavaScript (ES6+)
- Google Books API (for book cover images)
- CSS3 with custom properties

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge).
